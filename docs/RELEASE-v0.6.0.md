# monkey v0.6.0

Formal MIT-licensed release of the Python `monkey-native` package and `monkey` CLI. This release consolidates the native recovery and source-toolkit work on `main` and preserves existing branch history. It supersedes retired formatting implementations rather than reintroducing source-engine emulation into native projects.

## Changes

- Large-project parse budgets, stage reuse, exact resource identities, ownership-aware exports and explicit missing-source classifications.
- Source-linked C# drafts and Bootstrap/Domain/Gameplay/Presentation/Services architecture workflows, including bounded module execution, checkpoint recovery, inherited-member evidence and immutable candidate revisions.
- Seven source toolkit commands received through `monkey tool <id>`: `laya_contract_audit`, `read_elf_values`, `unpack_xapk`, `shader_probe`, `decrypt_v1mmwx_wxapkg`, `unpack_wxapkg`, `export_config_tables`.
- Public documentation and examples remove private project, machine and coordination details. Stable compatibility identifiers, public source URLs and required license attribution remain. Original private evidence is retained outside the release tree.

## Compatibility

`monkey --version` reports `0.6.0`. Existing `convert` and batch recovery commands remain available; consumers must verify the advertised `capabilities` and `grea-toolkit/1` contract rather than infer functionality from the version. Candidate `monkey-project/2.0.0` structure and source-side toolkit contracts remain distinct. Project adoption and development construction are delegated to beaver.

Optional Codex-backed workflows retain the existing Homebrew executable default and executable-identity checks. On other installations pass an explicit absolute executable path with `--codex`; Codex and native engines are not bundled. General offline resource export does not require these providers.

## Evidence and remaining limits

A representative private recovery candidate with 1,555 C# files compiled in five actual assemblies with 0 errors and 3,249 warnings. Scoped native integration checked 348 cells, 24 exact Sprite identities, source coordinates, rendering, production interaction, persistence/reopen and rejection of input outside the viewport. This is historical scoped evidence; private source material and full raw logs are excluded from public distribution. Two Editor Search startup exceptions remain recorded.

Generated business logic can remain partial or unreviewed. These observations do not establish complete gameplay, original visual parity, physical-device input, Player builds, remote-server reconstruction or support for every engine version. Empty source configuration tables remain explicitly empty; unavailable audio implementation is not replaced by fake successful playback.

## Distribution

Download the wheel, source archive and `SHA256SUMS` from the [v0.6.0 Release](https://github.com/chuxintec/monkey/releases/tag/v0.6.0). Verify the downloaded bytes before installing into an isolated Python 3.11+ environment. The wheel installs the `monkey` command and includes source-toolkit code, target templates and license notices; it contains no game originals, private candidates, engine binaries or credentials.

Publication, installation, native compilation and runtime acceptance have separate receipts. Global installation replacement is coordinated by the integration owner after the formal artifact identities are verified.
