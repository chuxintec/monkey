## 公开工具路径

以下命令为真实使用的产品入口；参数中的manifest、revision、spec必须以对应不可变文件的SHA256提供，输出必须为不存在的新目录：

```sh
monkey code-native-reassemble --run <完整模块run> --out <重新组装目录>
monkey code-native-revise --candidate <基线工程> --expected-manifest <manifest-sha256> \
  --revision <闭合修订目录> --expected-revision <revision-plan-sha256> --out <新工程>
monkey code-native-add-json --candidate <无JSON修订工程> --expected-manifest <manifest-sha256> \
  --spec <json-assets-spec.json> --expected-spec <spec-sha256> --out <最终工程>
```

源码开发环境也可使用 `.venv/bin/python -m monkey.cli` 调用同一执行层。修订合同见 `CODE-ARCHITECTURE-REVISION.md`，继承核验见 `CODE-ARCHITECTURE-INHERITANCE.md`。这些通用工具拒绝源/基线漂移、未知所有权、反向层依赖和静默覆盖；来源代码与审阅后的修订产物由具体恢复任务提供，公开包不携带私有游戏素材。

本次可原样复现的链及精确输入保留在 `.private/v060-architecture-first-20261027/CoreIntegrationExecution02/`：`run-complete-revision.py` → `final-revision.py` → `final-json.py`，以及其stdout/执行回执；冻结计划依次为 `NativeFullCoreRevisionPlan03`、`NativeFullCoreRevisionPlan04`、`NativeFullCoreJsonPlan03`。这些是通用公开API的实际调用，不是绕过manifest的私有手改。
